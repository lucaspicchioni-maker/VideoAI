## Kling AI — Complete Technical Reference

### API Authentication

```python
import os
import time
import hmac
import hashlib
import base64
import requests

KLING_API_KEY    = os.getenv("KLING_API_KEY")
KLING_API_SECRET = os.getenv("KLING_API_SECRET")
KLING_BASE_URL   = "https://api.klingai.com"

def get_kling_headers() -> dict:
    """Generate signed headers for Kling API authentication."""
    timestamp = str(int(time.time()))
    nonce     = base64.b64encode(os.urandom(8)).decode()
    message   = f"{KLING_API_KEY}{timestamp}{nonce}"
    signature = hmac.new(
        KLING_API_SECRET.encode(), message.encode(), hashlib.sha256
    ).hexdigest()
    return {
        "Content-Type": "application/json",
        "X-Api-Key":    KLING_API_KEY,
        "X-Timestamp":  timestamp,
        "X-Nonce":      nonce,
        "X-Signature":  signature,
    }
```

### Image-to-Video — Core Parameters

```python
def create_i2v_task(
    image_url: str,         # Frame A URL (Midjourney CDN)
    tail_image_url: str,    # Frame B URL (Midjourney CDN) — optional but ALWAYS use for control
    prompt: str,            # Movement prompt (ONLY movement + camera — never describe the image)
    negative_prompt: str,   # What must NOT happen
    duration: int,          # 5 or 10 seconds
    mode: str = "std",      # "std" = Standard 720p (tests) | "pro" = Pro 1080p (final)
    cfg_scale: float = 0.5, # 0.0–1.0: prompt adherence. 0.5 = balanced
) -> dict:
    payload = {
        "model_name": "kling-v1-5",   # Latest stable model
        "image": image_url,
        "image_tail": tail_image_url,
        "prompt": prompt,
        "negative_prompt": negative_prompt,
        "cfg_scale": cfg_scale,
        "mode": mode,
        "duration": str(duration),
        "enable_audio": False,         # ALWAYS False — audio added by Post-Production
    }
    response = requests.post(
        f"{KLING_BASE_URL}/v1/videos/image2video",
        headers=get_kling_headers(),
        json=payload,
    )
    return response.json()
```

### Parameters Deep Dive

| Parameter | Values | Production Rule |
|---|---|---|
| `model_name` | `kling-v1-5`, `kling-v2` | Use `kling-v1-5` for stable results; `kling-v2` for testing |
| `duration` | `5` or `10` | 5s for action/tension/emotion; 10s for establishing/romance/slow build |
| `mode` | `std` (720p) / `pro` (1080p) | ALWAYS test in `std` first; only render final in `pro` |
| `cfg_scale` | 0.0–1.0 | 0.3 = more creative; 0.5 = balanced; 0.7 = strict to prompt |
| `enable_audio` | `false` / `true` | ALWAYS `false` — audio mixed by Post-Production Director |
| `image_tail` | URL of Frame B | ALWAYS provide — it's what controls motion endpoint |
| `negative_prompt` | Text | ALWAYS define explicitly (see templates below) |

### The Golden Rule of Kling Prompting

> **Describe ONLY the movement and the camera. Never describe the image itself.**

The image IS the source of truth. Kling reads it. Your prompt directs what changes.

#### ❌ WRONG — Redescriving the image:
```
A handsome Brazilian man in a black suit sitting in a luxury penthouse with city lights
behind him slowly looks up and turns his head to the left
```

#### ✅ CORRECT — Movement + camera only:
```
Subject slowly lifts gaze from downward position, turns head 20 degrees to the left,
subtle shoulder shift. Camera holds steady. Motion settles into stillness at the cut.
```

### Prompt Templates by Scene Type

#### Tension / Reaction (5s)
```
Subject [specific micro-movement: e.g., jaw tightens, eyes narrow slightly].
Right hand [specific motion: e.g., tightens grip on phone].
Camera holds at eye level. Scene settles into stillness at cut.
No new objects. No background changes. No camera movement.
```

#### Dialogue / Lip Sync Setup (5–10s)
```
Subject begins speaking — natural jaw movement, subtle head micro-movements during speech.
Eyes remain directed at [target: e.g., slightly off-camera left].
Camera holds medium shot, no drift. Audio will be added in post.
No new objects. No other characters enter frame.
```

#### Establishing / Environment (10s)
```
[Slow camera move: e.g., gentle dolly forward / slow pan left / subtle crane up].
[Scale: e.g., 15% zoom over 10 seconds — barely perceptible].
No characters enter frame. Ambient environmental motion only:
[e.g., curtains sway slightly, candle flame flickers, city traffic through window].
Motion ends with camera fully settled.
```

#### Emotion Peak — Cliffhanger (5s)
```
Subject freezes for 1 second, then [single decisive movement: e.g., turns sharply
away from camera, raises phone to ear, drops object from hand].
Camera snap-zooms in 10% on the final beat, then holds.
No dialogue. No new objects. Hard cut expected after stillness.
```

#### Romance / Approach (10s)
```
Subject [gradual motion toward off-screen second person: e.g., leans 15 degrees forward,
extends right hand slowly, eyes soft focus].
Camera drifts 5 degrees right on a 10-second arc to follow motion.
Background bokeh maintains depth. Motion ends with subject in new resting position.
```

#### Flashback / Memory (5s)
```
No subject movement. Camera applies [slight vintage motion: e.g., barely perceptible zoom out,
subtle film grain visual treatment if supported].
Environment holds completely still. This is a frozen memory.
```

### Negative Prompt Templates

**Standard (use in every clip):**
```
no new objects, no new characters, no text, no watermark, no logo,
no camera shake, no jump cut, no scene change, no teleportation,
no walls being crossed, no objects passing through solid surfaces,
no floating elements, no sudden color change, no flicker
```

**Interior / Architecture scenes (add):**
```
no doors opening, no walls moving, no furniture repositioning,
no window reflections changing, no spontaneous light changes
```

**Character scenes (add):**
```
no clothing change, no hairstyle change, no body proportions change,
no face deformation, no extra limbs, no merging with background
```

**Luxury/Party scenes (add):**
```
no random crowd appearing, no glasses or bottles multiplying,
no spontaneous confetti or effects
```

### Lip Sync — Complete Protocol

#### Eligibility Criteria (ALL must be met)

| Criterion | Requirement | How to Check |
|---|---|---|
| Audio duration | ≥ 2.0 seconds | Check `handoff-ep[XX].md` from Sound Director |
| Face angle | 0–15 degrees frontal | Check Frame A image — ask Midjourney Director if uncertain |
| Face occlusion | None — no hair, hands, mask covering mouth | Check Frame A |
| Face size | Occupies ≥ 25% of frame height | Check Frame A |
| Audio clarity | Clean, no heavy reverb/SFX mixed in | Use raw dialogue file, not mixed version |

#### ⚠️ If audio < 2 seconds:
Do NOT attempt Lip Sync. Flag in handoff: **"Needs FFMPEG padding → Post-Production Director."**

#### Lip Sync API Call

```python
def create_lip_sync_task(
    video_url: str,          # URL of the already-generated I2V clip
    audio_url: str,          # URL of the clean dialogue audio file
    origin_task_id: str,     # Task ID from the I2V request — ALWAYS chain this way
) -> dict:
    payload = {
        "video_url":       video_url,
        "audio_url":       audio_url,
        "origin_task_id":  origin_task_id,   # Links the lip sync to the original generation
    }
    response = requests.post(
        f"{KLING_BASE_URL}/v1/videos/lip-sync",
        headers=get_kling_headers(),
        json=payload,
    )
    return response.json()
```

#### Chaining Rule — `origin_task_id`
Always link Lip Sync to the original I2V task via `origin_task_id`. This ensures:
- Kling's model has full context of the original motion
- Output maintains temporal consistency with the base video
- Any re-render is tied to the same generation chain

### Task Polling — Wait for Completion

```python
import time

def poll_task(task_id: str, task_type: str = "image2video", timeout: int = 600) -> dict:
    """
    Poll a Kling task until completion or timeout.
    task_type: 'image2video' or 'lip-sync'
    """
    endpoint_map = {
        "image2video": f"/v1/videos/image2video/{task_id}",
        "lip-sync":    f"/v1/videos/lip-sync/{task_id}",
    }
    endpoint = endpoint_map[task_type]
    deadline = time.time() + timeout

    while time.time() < deadline:
        response = requests.get(
            f"{KLING_BASE_URL}{endpoint}",
            headers=get_kling_headers(),
        )
        data = response.json()
        status = data.get("data", {}).get("task_status")

        if status == "succeed":
            return data
        elif status == "failed":
            raise RuntimeError(f"Kling task {task_id} failed: {data}")
        elif status in ("submitted", "processing"):
            print(f"[Kling] Task {task_id} — {status}. Waiting 15s...")
            time.sleep(15)
        else:
            raise RuntimeError(f"Unexpected status: {status}")

    raise TimeoutError(f"Kling task {task_id} did not complete within {timeout}s")
```

## Complete Workflow per Episode

### Step 1 — Receive Handoffs
Read:
- `prompts/T[N]/ep[XX]-prompts.md` → get all Frame A + Frame B URL pairs
- `audio/ep[XX]/handoff-ep[XX].md` → identify which scenes need Lip Sync

### Step 2 — Generate Motion (Standard Mode First)

For each scene pair (Frame A, Frame B):
1. Write movement prompt (movement + camera only)
2. Write negative prompt (use standard template + scene-specific additions)
3. Call `create_i2v_task()` with `mode="std"`
4. Store returned `task_id` mapped to scene number
5. Poll until complete
6. Preview with user before rendering final

### Step 3 — Lip Sync (When Eligible)

For each scene flagged in Sound Director handoff:
1. Verify all 5 eligibility criteria (duration, face angle, occlusion, size, audio quality)
2. If any criterion fails: skip Lip Sync, note in post-production handoff
3. Call `create_lip_sync_task()` with the I2V task's URL + audio URL + `origin_task_id`
4. Poll until complete

### Step 4 — User Review

Present all Standard clips to user:
- Approved → rerender in Pro (`mode="pro"`)
- Needs adjustment → modify prompt and re-run in Std
- Fundamental problem (face inconsistency, wrong motion) → escalate to Midjourney Director for new frames

### Step 5 — Final Render (Pro Mode)
Re-run approved clips in `mode="pro"`.
Save output URLs in the Post-Production handoff.

## Error Reference

| Error | Cause | Fix |
|---|---|---|
| Task fails immediately | Invalid image URL / expired CDN link | Re-upload image to stable storage, use new URL |
| Motion destroys face | `cfg_scale` too low + vague prompt | Increase `cfg_scale` to 0.6–0.7, be more specific |
| Lip sync misaligned | Audio file has silence padding | Use raw audio from Sound Director (pre-padding) |
| Clothing change mid-clip | Weak negative prompt | Add `no clothing change` to negative prompt |
| Character walks through wall | Missing physics negatives | Add `no walls being crossed, no objects passing through solid surfaces` |
| Lip sync rejected (no face) | Face < 25% of frame height | Use a tighter crop from Midjourney — flag to MJ Director |
| Task never completes | Server overload | Retry after 5 minutes; use exponential backoff |
