# Character References — Danilo Vasconcelos Series

## How to Use
Each character has a fixed description and a Midjourney reference image URL.
Always use `--cref [URL] --cw 100` in every prompt featuring that character.
**NEVER proceed with an episode if a featured character has no reference image.**

## DANILO VASCONCELOS (Protagonista)
**Inspired by:** Daniel Vorcaro

**Reference Image (42 anos):** https://cdn.midjourney.com/80110a08-e749-4e07-9e1a-0623f23107cc/0_1.png
**Reference Image (30 anos):** https://cdn.midjourney.com/2fceeb51-c126-4647-9494-693423e74acc/0_3.png
**Reference Image (22 anos):** https://cdn.midjourney.com/a5e68ea7-8528-4c08-8d63-e583939b7158/0_0.png
**Reference Image (15 anos):** https://cdn.midjourney.com/0fb36c84-aa26-4787-b8ea-7fc2686dbe6f/0_0.png

**Fixed Description (42 anos):**
> Man, 42, strong angular jaw, dark brown hair slicked back with subtle gel, full groomed beard, light brown piercing confident eyes, permanent slight smile, medium athletic build, perfectly tailored charcoal Italian suit, gold watch, effortless commanding posture, slight tan

**Fixed Description (30 anos):**
> Confident man, 30, dark hair slicked back more refined, beginning of carefully groomed stubble, light brown eyes sharper and colder, perfectly fitted dark suit white shirt open collar, first expensive watch, slight tan, same smile but the eyes have changed

**Fixed Description (22 anos):**
> Young ambitious man, 23, dark brown hair slicked back with gel first attempt at executive style, clean-shaven revealing sharp angular jaw, light brown piercing hungry eyes, slightly oversized suit with bold tie, trained television smile

**Fixed Description (15 anos):**
> Teenage boy, 16, dark brown wavy hair neatly combed, light brown eyes already too sharp and confident for his age, angular jaw forming, slight knowing smile, elite private school uniform polo shirt, slim build

**Key Traits:**
- Enters any room as if he owns it
- Never raises his voice
- Makes everyone feel special in his presence
- Was smiling when arrested — cameras confirmed
- Never admits failure — rewrites every defeat as part of the plan
- Mixes faith and business as if they were the same language

**Signature Quotes:**
- "O sistema não foi feito pra ser obedecido. Foi feito pra ser compreendido."
- "Deus abençoa quem tem coragem de sonhar grande."
- "Eu nunca roubei nada. Eu aproveitei oportunidades que outros tinham medo de ver."
