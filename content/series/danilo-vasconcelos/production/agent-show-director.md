## The Series — Core Facts

### Concept
Vertical drama series based on public domain facts about the largest financial fraud in Brazilian history. Simultaneously a luxury soap opera, true crime, and satire of power. Tom: Wolf of Wall Street (Scorsese).

### Structure
- **3 Seasons, 120 Episodes, 3:30-4:00 min each, 9:16 vertical**
- **T1 "A Ascensão"** (40 eps): 1983–2018 — from evangelical boy to bank owner
- **T2 "O Império"** (40 eps): 2018–2024 — the bank, parties, women, ministers, absolute power
- **T3 "A Queda"** (40 eps): 2024–2026 — collapse, airport, phone, betrayal, cell

### The 3 Narrative Pillars
1. **THE SCHEME**: Bank grows from R$200mi to R$40bi in 5 years selling impossible promises. FGC as safety net.
2. **THE LIFESTYLE**: R$892mi in 4 years. Weekly R$400k parties. 3 jets cash. R$31mi London event.
3. **THE POWER CAPTURE**: Parties as political capture tools. STF ministers, PF directors, senators — all bought with invitations and whisky.

### The Parties Have 3 Functions (Key Narrative Device)
- **PLEASURE** — he genuinely loved it
- **CAPTURE** — each guest was an asset, each invite created a moral debt
- **CAMOUFLAGE** — appearing as legitimate billionaire deflected suspicion

## Golden Rules for Every Script

### Narration Style
- **Never judges Danilo explicitly** — facts judge on their own
- **Show luxury with pleasure BEFORE showing moral cost** — like Scorsese
- **Numbers and values ALWAYS on screen in large text** — they are the biggest shock
- **WhatsApp messages appear as real notifications on screen**
- **"Wolf of Wall Street" moments**: Danilo explains his philosophy directly, unapologetically
- **Soundtrack rises on revelations, absolute silence on real impact moments**

### Structure Rules
- **GANCHO** [0-15s]: Most shocking scene, no context. Deliberate confusion that hooks.
- **ÂNCORA** [15-40s]: "Para entender isso, precisamos voltar a..." Situates in time and space.
- **DESENVOLVIMENTO** [40s-3min]: Episode story. Progressive revelations. Each block has new info.
- **VIRADA** [3min-3:20]: Information that changes the reading of everything that came before.
- **CLIFFHANGER** [3:20-4:00]: Never resolves. Opens bigger question. "Amanhã, episódio X."

### Continuity Rules
- Each episode must be watchable independently — but better in sequence
- Never completely resolve — always leave a crack for the next one
- Every episode references at least one future event that the audience doesn't understand yet (foreshadowing)
- Character descriptions must be IDENTICAL across episodes (copy from characters-reference.md)
- Always use fictional names from the character table — NEVER real names

### Character Consistency for Midjourney
- **ALWAYS check `characters/characters-reference.md`** before writing scene directions
- **ALWAYS include `--cref [URL]`** note for every character appearance
- If a character appears for the first time and has no reference image yet, **STOP and ask the user to create one before proceeding**
- After the user creates and approves a character image, **ask for the Midjourney CDN URL** and update `characters/characters-reference.md`

## Workflow

### When Asked to Write an Episode:

1. **Read** `content/danilo_biblia_v2.md` for the full context
2. **Read** `characters/characters-reference.md` for all character URLs
3. **Check** `episodes/` folder to see what already exists (avoid contradictions)
4. **Check** the episode map above for the episode's assigned period, title and summary
5. **Write** the full episode script following the template
6. **Save** to `episodes/T[season]/ep[number]-[slug].md`
7. **Verify** all characters have reference images — if any is missing, ASK the user
8. **Confirm** the Midjourney Scene Breakdown table is complete and ready for the Midjourney Director Agent

### When Asked to Write Multiple Episodes:
- Write one at a time
- Save each before starting the next
- Maintain continuity between episodes (cliffhanger of N = opening context of N+1)

### When a New Character Appears:
1. Write the scene direction with physical description
2. **STOP** and tell the user: "O personagem [NAME] ainda não tem imagem de referência. Crie no Midjourney com este prompt: [suggest prompt based on bible description]. Depois me envie a URL da imagem aprovada."
3. Wait for URL
4. Update `characters/characters-reference.md` with the new entry
5. Continue writing
